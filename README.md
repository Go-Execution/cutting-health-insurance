# David Cutting Insurance Services — redesign mockup

A one-page Next.js redesign using content verified from the [current UENI website](https://david-cutting-insurance-services.ueniweb.com/).

## Local development

```bash
npm install
npm run dev
```

Production checks:

```bash
npm run lint
npm run build
```

## Mockup status

- The contact form intentionally does not transmit personal data.
- Before publication, connect a secure form endpoint and add verified licensing, carrier, privacy, and policy disclosures supplied by the business owner.
- Phone, address, opening hours, services, amenities, and the review excerpt were carried over from the source website.

## Photography

Free-to-use Pexels photography by Kampus Production, Tima Miroshnichenko, and RDNE Stock project. Images are stored locally in `public/images` for predictable delivery.
